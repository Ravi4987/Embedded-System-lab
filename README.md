Embedded Systems Lab

Welcome to Embedded Systems Lab, a collection of hands-on projects, source code, and experiments covering embedded firmware development and systems programming.

This repository includes:

- C Programming: Core concepts, algorithms, and practical implementations.
- C++ Programming: Object-oriented programming, STL, and modern C++ concepts.
- Arduino: Microcontroller projects, sensor interfacing, and hardware experiments.
- STM32: Bare-metal programming, peripheral drivers, communication protocols, and FreeRTOS.
- Embedded Linux: Linux device drivers, kernel modules, device trees, and system-level programming.
- Bootloaders: Firmware update mechanisms and bootloader implementations.

Purpose

To explore, implement, and share practical embedded systems concepts through real-world examples, experiments, and reusable code.
